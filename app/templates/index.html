How to Train the Model

You can train or fine-tune the brain tumor classification model directly using the provided training pipeline:

1. Standard Training Command:

python training/train.py --epochs 10 --batch-size 32 --lr 0.0005 --backbone mobilenet_v3

2. Quick Smoke-Test (20% subset):

python training/train.py --epochs 2 --batch-size 32 --subset 0.2

3. Evaluate on 1,000-image Test Set:

python training/evaluate.py --model-path models/best_model.pt

4. CLI Parameters:

  • --epochs: Number of training cycles (default: 5)
  • --batch-size: Images per batch (default: 32)
  • --lr: Learning rate for AdamW optimizer (default: 0.0005)
  • --backbone: Architecture (mobilenet_v3, resnet18, or custom)
  • --device: Device to compute on (cpu or cuda)
